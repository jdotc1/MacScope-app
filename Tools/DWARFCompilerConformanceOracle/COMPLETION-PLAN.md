- change meaningful address, name, array bound, signedness, parameter count/order or variadic state: comparator must detect the affected semantic field;
- change only terminal isStmt: comparator must ignore that field while still detecting terminal address corruption;
- drop a CU: positional root matching must report missing evidence, not relabel later roots as earlier CUs;

- observed type grammar conservatively marks 42 qualifier cases unsupported; arrays with multiple dimensions and complex pointer/qualifier binding need explicit normalization tests.
- no-return semantics, full canonical source-path identity, local-expression semantics and range-expression field coverage remain incomplete.

After comparator-only corrections, reuse stored observations wherever input and product identity are unchanged. New reference traversal may be justified for fields that were not retained, but it is a new action to scope, not a reason to rerun the product corpus.
