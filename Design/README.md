# Design sources

- `LumenCatalog.icon`: the Lumen Catalog app icon, an Icon Composer document (Liquid Glass; Default,
  Dark and Mono appearances). Open it in Icon Composer.app to edit. Four component tiles in Lumen hues,
  the violet one carrying the Catalog's spark, on a violet ground (deep violet in dark).
- `catalog-icon-build.py`: the script that generated the concepts and this document's starting point.
- `Scripts/install-catalog.sh` builds the Catalog in release and installs `/Applications/Lumen Catalog.app`
  with this icon compiled by `actool`.
