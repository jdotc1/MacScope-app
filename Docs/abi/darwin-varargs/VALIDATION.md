Input: `MacScope_Darwin_Varargs_Lab_v1_2026-10-22.zip` (1,080 files; `PACKAGE_MANIFEST.json` lists the other 1,079, and every SHA-256 and byte length matched on extraction). Checked against MacScope `main` at `5bbc56d5d`; the lab pinned `e3285cb9` (PR 962), one merge earlier, and every source line it cites (binder lines 482–490 and 440–447, `MacIR.swift` 1160–1200, `MacIRBuilder+State.swift` 2234–2322) still says what the lab says.

Its own receipts are cited as they are: `reports/EXECUTION_SUMMARY.json` (1,677 scenarios, 6,700 executions, 48,676 read comparisons, zero failures) and `reports/final_tests.txt` (171 Python tests passed). Those numbers come from a Linux host running Zig 0.15.2 / Clang 20.1.2 under Unicorn. The Apple witness below re-checks the rules on this Mac with Apple clang, for both architectures.

## Limits that still apply

- The Apple witness covers scalar, `__int128`, `long double`, one indirect record, one HFA and a few named prefixes, at `-O0`. It is a focused set, not a sweep; x86_64 ran under Rosetta, not on Intel hardware.
- The cursor needs a real callee-entry SP and an immutable snapshot of incoming stack memory. A static binary does not supply those. No `LoadedBinary` read path or runtime capture is added.
- Excluded, and refused rather than guessed: arm64e/PAC, Swift calling conventions, C++ non-trivial records, unions, vectors, packed or over-aligned records, half-precision HFAs, x86_64 records (only scalar classes are modelled), and Windows x64.
